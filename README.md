# 📋 Análise e Projeto de Sistemas (APS)

Repositório oficial dedicado aos materiais, exercícios práticos e ao projeto integrador desenvolvidos ao longo da disciplina de **Análise e Projeto de Sistemas**.

---

## 🎯 Sobre a Disciplina

Disciplina voltada para o estudo aprofundado de metodologias e técnicas modernas de análise, modelagem e projeto de sistemas de software. O foco principal é capacitar o estudante na especificação de sistemas robustos, escaláveis e alinhados às necessidades do negócio, abordando desde a concepção até a documentação técnica.

### 📚 Conteúdos Abordados

*   **Engenharia de Requisitos:** Elicitação, análise, especificação e gerência de requisitos funcionais e não-funcionais.
*   **Análise Orientada a Objetos (OO):** Identificação de classes, atributos, métodos, relacionamentos e padrões de projeto iniciais.
*   **Modelagem UML (Unified Modeling Language):** Construção e interpretação de diagramas essenciais para a Engenharia de Software:
    *   Diagramas de Caso de Uso
    *   Diagramas de Classes
    *   Diagramas de Sequência
    *   Diagramas de Atividades
*   **Projeto de Sistemas:** Arquitetura de software, design de interfaces e modelagem de dados.
*   **Documentação de Software:** Elaboração de artefatos padronizados para o ciclo de vida do desenvolvimento de sistemas (SDLC).
